KEY COMPONENTS:

📁 Files Involved:
  Frontend:
    - src/components/UploadZone.jsx
    - src/components/ResultsViewer.jsx
    - src/services/api.js
  
  Backend:
    - backend/app.py (API endpoints)
    - backend/detection_service.py (Service layer)
    - backend/database.py (MongoDB operations)
  
  Detection:
    - central_detection_manager.py (Main detection logic)
    - detect_helmet.py (Helmet detection)
    - license_plate_detection/ (License plate detection)

🔧 Models Used:
  - yolov8n.pt (Triple riding - base COCO model)
  - best.pt (License plate - trained model)
  - best.pt (Helmet - trained model)
  - traffic_light_classifier.h5 (Red light - trained CNN)

📊 Data Flow:
  1. Image uploaded → Saved to uploads/
  2. All 4 detections run in parallel
  3. Results combined and formatted
  4. Saved to MongoDB
  5. Returned to frontend as JSON
  6. Displayed in beautiful UI

✅ TRIPLE RIDING DETECTION VERIFIED:
  - Model: yolov8n.pt ✅
  - Class IDs: 0=person, 3=motorcycle ✅
  - Logic: Counts persons near motorcycles ✅
  - Threshold: >= 3 persons = violation ✅
  - Drawing: Red box on bike, blue on persons ✅
  - Response: Included in JSON ✅
  - Display: Shows in frontend table ✅
